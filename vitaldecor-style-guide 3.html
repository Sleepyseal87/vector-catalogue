VITALDECOR STYLE GUIDE
Simplified Palette – Sombre & Dramatic
Design Philosophy
Sombre foundation, red impact. The palette is deliberately dark and desaturated. Red is used sparingly for maximum impact – pricing, key headers, and thin accent lines only. This creates tension: dark, serious technical documentation punctuated by sharp red moments.

Color Application Strategy
DARK ZONES (Sombre Foundation)
• Mood page: Full dark gradient (#1F2937 → #1a1a1a)
• Product showcase: Dark gradient background
• Table headers: Dark gradient with white text
• Price blocks: Pure black (#1a1a1a) background

Goal: Create tension, make red pop
RED IMPACT MOMENTS
• Price numbers (48-72px, bold)
• Section headers (uppercase, 14-18px)
• Thin accent bars (2-4px height)
• Stock checkmark color

Rule: Use sparingly = maximum impact
LIGHT ZONES (Readability)
• Spec page main background: White
• Table cells: White or #F5F5F5
• Body text: #1a1a1a on white
• Borders/dividers: #E8E8E8

Goal: Maximum technical legibility
NEVER USE
✗ Red as background color (too aggressive)
✗ Brass/gold tones (old palette)
✗ Multiple bright colors
✗ Gradients on body text
✗ Dark grey text on dark backgrounds
✗ More than 2 font families
